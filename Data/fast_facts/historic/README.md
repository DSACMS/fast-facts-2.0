The Fast Facts page on [Data.CMS.gov](https://data.cms.gov/fact-sheet/cms-fast-facts) provides the most product release. Prior year releases are not currently posted to [Data.CMS.gov](https://data.cms.gov/fact-sheet/cms-fast-facts), but necessary for trend analysis. This project uses Fast Facts released from 2021 onwards. These files are maintains by [OEDA/IPAG](PAG_Data_Products@cms.hhs.gov).

Contents locally stored for this project include the following files:

   -  CMSFastFactsNov2021.xlsx
   -  CMSFastFactsAug2022.xlsx    
   -  CMSFastFactsOct2023_508.xlsx
   -  CMSFastFactsMar2024_508.xlsx
   -  CMSFastFacts2025_508.xlsx
